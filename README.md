# Clear Vision — Hospitality Sentiment Repair Agent

An intelligent web-based sentiment analysis and guest experience repair system designed for hotels and hospitality businesses.

## Features

- **Sentiment Analysis**: Analyze guest reviews, ratings, and feedback to detect pain points and critical satisfaction drivers.
- **Service Recovery & Repair**: Automated response drafting, mitigation strategies, and sentiment recovery workflows.
- **Modern UI / UX**: Light & Dark mode support, interactive dashboards, real-time analytics, and luxury hospitality aesthetic.
- **Standalone Web App**: Fully self-contained client-side application ready for GitHub Pages.

## Live Demo & Usage

Open `index.html` (or `hospitality-sentiment-agent (1).html`) in any modern web browser or host on GitHub Pages.
